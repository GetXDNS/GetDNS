# GetDNS

دانلود رسمی اپلیکیشن GetDNS برای اندروید.

کانال رسمی: [@GetXDNS](https://t.me/GetXDNS)

فایل‌ها در پوشهٔ `apk/` هستند. اپلیکیشن هنگام به‌روزرسانی، هش SHA-256 و امضای هر فایل را بررسی می‌کند و فایل دست‌کاری‌شده را نصب نمی‌کند.

---

Official Android downloads of GetDNS. The app checks each file's SHA-256 and signature before installing an update.
